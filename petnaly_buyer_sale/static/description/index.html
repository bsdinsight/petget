Petnaly: Buyer & Sale

Buyers, reservations, deposits and sales — the practical way.

What this module does

  • Buyers — kept on Odoo contacts (res.partner) with a buyer flag, set automatically when you create a reservation.
  • Reservations — auto reservation ID and a clear state machine: Reserved → Deposit Received → Sold (or Cancelled).
  • Deposits & sale — record deposit and sale amounts and dates manually.
  • Automatic ownership transfer — completing a sale sets the animal's owner and status, and updates its sale status.

Requires the free Petnaly: Core module. No invoicing or payment automation — by design.
